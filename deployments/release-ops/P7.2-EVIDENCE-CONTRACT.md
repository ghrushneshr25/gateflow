# P7.2 — Evidence Contract (Protocol A Shared Staging)

**Status:** Contract / procedure only. Does **not** claim shared staging was executed.  
**Execution procedure companion:** `STAGING-RUN-PLAN.md`  
**Latency definitions:** `GRANT-LATENCY-SLO.md`  
**Rollback procedure:** `ROLLBACK-PLAN.md`  
**Evidence index template:** `docs/phase-7/results/P72-evidence-index.json` (local engineering path; may be gitignored)

---

## 1. Purpose

Make P7.2 auditable: every gate has a stable ID, procedure, proof artifacts, pass/fail rule, owner role, and status vocabulary. A successful command alone is insufficient if it does not prove the invariant.

**Protocol:** Admission **A only**. Protocol B remains disabled.  
**Production:** Not authorized by this contract or by a P7.2 PASS.

---

## 2. Status vocabulary

| Status | Meaning |
|---|---|
| `PASS` | Required test ran **in shared staging**; evidence meets acceptance rule |
| `FAIL` | Test ran; acceptance criterion failed |
| `BLOCKED` | Environment, dependency, access, or artifact unavailable |
| `NOT_RUN` | Not attempted |
| `NOT_VERIFIED` | Activity incomplete or proof missing/inconclusive |
| `CONDITIONAL` | Overall milestone only — unresolved non-hard-stop gates |

**Local Docker / laptop results cannot satisfy gates that require shared staging.**

---

## 3. Hard stops (block overall PASS and production review)

Any of the following observed in staging → overall verdict cannot be `PASS`; stop release progression:

1. Inventory **oversell** (confirmed + active reserved > sellable)  
2. **Budget overflow** (purchase-limit invariant broken)  
3. **Fence bypass** (grant succeeds while fenced / coordination uncertain)  
4. Demonstrated **durable business-effect loss** or non-idempotent duplicate effect

## 5. Gate catalog

### G1 — `deployment_identity`

**Purpose:** Prove what was deployed, where, and with which config.  
**Owner role:** `release_owner` + `platform_owner`

| | |
|---|---|
| **Artifacts** | `P72-deployment-manifest.json`, `P72-service-health.txt`, `P72-admission-replicas.json`, migration output |
| **Procedure** | Record env ID, deploy ID, Git SHA, **image digests**, config rev, UTC times; healthz ×5; migration versions; Kafka + topics; `/v1/meta` on **each** admission replica |
| **Pass** | All services healthy; **every** admission replica `grant_protocol=A`; digests recorded; migrations OK; non-dev secrets; no unknown artifacts |
| **Fail/stop** | Protocol mismatch, unknown digest, failed dependency, unsafe secrets |

#### G1 unblock criteria (all required)

A staging **URL alone does not unblock** G1 or the milestone. Before clearing G1 `BLOCKED` / starting the run plan, platform + release must supply:

1. **Usable `environment_id`** and account/access for the shared staging environment  
2. **Deploy permissions** and a documented path to deploy/inspect the five services  
3. **Connectivity** to PostgreSQL, Kafka, and required observability dependencies  
4. **Release candidate** Git SHA and **immutable image digests** (or equivalent reproducible artifacts)  
5. **Non-development secrets** injected for staging (not default local JWT secrets)  
6. Ability to **list and query every admission replica** for `/v1/meta` (`grant_protocol=A`)  

Additionally identify (may remain open risks until their gates run, but must be named before claiming those gates are runnable):

- **Prior approved artifact digest** for G8 rollback  
- **External alert notification channel** for G7 delivery proof  

Local Docker Compose evidence never satisfies G1 PASS.

## 6. Evidence index schema (per gate)

Each entry in `P72-evidence-index.json` **gates[]** must include:

```json
{
  "gate_id": "G1_deployment_identity",
  "title": "Environment and deployment identity",
  "status": "NOT_RUN",
  "environment_id": "",
  "environment_class": "shared_staging | local_lab | unknown",
  "git_sha": "",
  "image_digests": {},
  "started_at_utc": "",
  "finished_at_utc": "",
  "commands_or_procedure": "",
  "artifact_paths": [],
  "acceptance_criteria": "",
  "observed_result": "",
  "owner": "",
  "reviewer": "",
  "limitations": "",
  "hard_stop_triggered": false,
  "evidence_sha256": {}
}
```

### PASS eligibility rules (validator-enforced)

A gate may be marked `PASS` only if:

1. `environment_class` is `shared_staging` (not `local_lab`)  
2. `git_sha` non-empty  
3. `started_at_utc` and `finished_at_utc` non-empty  
4. `artifact_paths` length ≥ 1  
5. `owner` and `observed_result` non-empty  
6. `hard_stop_triggered` is false  
7. For `G6_performance_classified`: linked performance JSON satisfies class reconciliation and 5xx SLO rules  

### Overall verdict rules

| Verdict | When |
|---|---|
| `PASS` | All mandatory gates `PASS`; no hard stop; G7 external alert + G8 rollback demonstrated |
| `CONDITIONAL` | Staging ran; only non-hard-stop gaps remain with owners |
| `BLOCKED` | Shared staging or required dependency unavailable |
| `FAIL` | Required criterion failed or hard stop observed |
| `NOT_RUN` | Contract ready; shared staging execution not started |

## 7. Performance SLO application (G6)

See `GRANT-LATENCY-SLO.md`.

| Measurement | Target |
|---|---|
| Scenario G grant p95 @ c1,c5,c10,c20 | &lt; 50 ms |
| Scenario C checkout p95 @ c10 | &lt; 200 ms |
| Unexpected HTTP 5xx | &lt; 1% of attempts **and** unclassified = 0 **and** sum(classes) = attempts |
| Scenario D oversell | 0 |
| Full-journey grant @ c20 | **Report only** unless CTO approves a separate target |

Transport errors are **not** HTTP 5xx.

## 9. Prerequisite: shared staging availability

### Finding scope (wording)

State what is **known from repository/configuration and the current workspace**, not what may exist elsewhere in the organization:

- If only local Docker Compose (or equivalent lab) is configured here → milestone **`BLOCKED`** for shared-staging execution.  
- That does **not** assert that no staging environment exists anywhere in the org—only that **this milestone is not bound** to a usable shared staging target.

### Unblock list

See **G1 unblock criteria** above. Also ensure:

- Multi-replica admission where staging topology requires it  
- Isolated Kafka topics for crash tests  
- Obs stack + external alert channel (for G7)  
- Prior approved artifact (for G8)  
- Named role holders (for G9/G10)

**Do not** substitute local Docker and claim G1–G10 PASS.
